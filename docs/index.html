服务器部署

Docker Compose

准备好 Docker 和 Compose，运行下面的命令。
数据持久化到 Docker 卷，重启后继续使用。

git clone https://github.com/duolabmeng6/ai-agent-file-hub.git
cd ai-agent-file-hub
docker compose up -d
查看 Compose ↗

启动后访问 http://服务器 IP:18787

首次打开　跟随页面设置管理员账号，即可开始管理文件。
