afile 命令参考

查询命令、复制示例，也可以把这份文档交给你的 Agent。

适用于 v1.0.13 · 命令以当前版本的 --help 为准

afile 已包含 Web 服务、CLI 和 MCP。这里假设 Agent 已完成安装，可在终端调用 afile；未加入 PATH 时请使用它的完整路径。

快速上手

在本机启动后台服务并打开浏览器，然后检查状态。

启动与检查
afile serve --host 127.0.0.1 --port 9000 --background --open
afile status --json
afile url

无参数执行 afile 会在前台启动服务。afile serve --background 由 CLI 管理，可使用 stop 和 restart。前台服务使用 Ctrl+C 停止。

服务管理

命令用途参数与说明
afile init准备本地状态目录--root、--open、--host、--port；--root 只创建目录，不配置储存器。
afile serve启动 Web 服务--host、--port、--background、--open。默认前台运行。
afile open在浏览器打开工作台--path 指定页面路径。
afile status查询服务与登录状态搭配 --json 输出结构化结果。
afile stop停止由 CLI 启动的后台服务只管理 afile 的本地后台进程。
afile restart重启后台服务--host、--port 可覆盖地址；--open 打开浏览器。
afile logs查看后台服务日志--tail 默认 100 行；--follow 或 -f 持续跟踪。
afile doctor检查本地状态与服务连接检查状态文件、目录可写性及服务是否就绪。
afile url输出当前工作台地址优先使用本地后台服务记录。
afile help [command]查看命令帮助也可以在任意子命令后加 --help。
afile completion [bash|zsh|fish|powershell]生成 Shell 补全脚本用 afile completion --help 查看当前 Shell 的安装方法。
查看最近日志并持续跟踪
afile logs --tail 50 --follow

MCP 配置

在 Web 工作台创建协作目录并获取访问码，将示例中的 WORKSPACE_CODE 替换为真实访问码。

命令用途参数与说明
afile mcp config <code>输出工作区的 MCP 客户端配置--name 设置服务名称，默认 agent-file-hub；--json 输出 JSON。
生成 MCP 客户端配置
afile mcp config WORKSPACE_CODE --name my-files --json

Workspace 文件操作

<code> 是协作目录的访问码；<path> 是该工作区内的相对路径，权限由 Web 中的协作配置决定。

命令用途参数与说明
afile workspace info <code>查看工作区信息访问码对应 Web 中创建的协作目录。
afile workspace ls <code> [path]列出文件与目录--page-size 默认 200；--cursor 继续分页。
afile workspace meta <code> <path>查看文件或目录元数据返回类型、大小等信息。
afile workspace read <code> <path>读取 UTF-8 文本默认输出正文；--json 返回结构化信息。
afile workspace write <code> <path>写入 UTF-8 文本--content、--file、--stdin 必须三选一。
afile workspace upload <code> <local-file> <path>上传一个本地文件适用于图片、PDF 等二进制文件。
afile workspace blob <code> <path>读取二进制内容--to 保存到本地；--base64 输出 Base64。
afile workspace download <code> <path>下载工作区文件--to 指定保存路径；未指定时输出到标准输出。
afile workspace mkdir <code> <path>创建目录路径位于当前工作区内。
afile workspace rm <code> <path>删除文件或目录必须加 --yes 确认；--type 可指定 file 或 directory。
afile workspace mv <code> <path> <target-path>移动或重命名源路径和目标路径均位于工作区内。
afile workspace search <code> <query>按文件名搜索--path 限定目录；--limit 默认 50；--mode 默认 filename。
列目录与读取文档
afile workspace ls WORKSPACE_CODE /
afile workspace read WORKSPACE_CODE notes/todo.md
从本地文本写入工作区
afile workspace write WORKSPACE_CODE notes/todo.md --file ./todo.md
上传与下载文件
afile workspace upload WORKSPACE_CODE ./report.pdf docs/report.pdf
afile workspace download WORKSPACE_CODE docs/report.pdf --to ./report.pdf
在指定目录按文件名搜索
afile workspace search WORKSPACE_CODE report --path docs --limit 20 --json

写文本时，--content、--file 与 --stdin 必须三选一。删除命令需要 --yes 明确确认；删除前先核对访问码和路径。

全局参数

全局参数可用于各级子命令。显式指定 --server 时使用该地址，否则优先使用本地后台服务记录，最后使用 http://127.0.0.1:9000。

参数默认值说明
--serverhttp://127.0.0.1:9000目标服务地址，显式指定时覆盖本地服务记录。
--jsonfalse使用 JSON 输出。
--outputtable输出格式：table、json、plain；不同命令按其结果类型输出。
--timeout30sHTTP 请求超时，例如 60s。
--config~/.afile/config.yamlCLI 配置路径；其所在目录用于本地状态文件。
--debugfalse调试标记；当前版本没有额外的诊断输出。
--help / -h—查看当前命令的用法和参数。
连接 Docker 部署的服务
afile --server http://127.0.0.1:18787 workspace ls WORKSPACE_CODE / --json

使用说明

  • 本机示例使用端口 9000；官网 Docker Compose 默认对外端口是 18787。连接其他服务器时请替换主机地址。
  • stop、restart 与 logs 管理由 CLI 启动的本地后台服务。Docker 部署使用 Docker Compose 管理生命周期。
  • Workspace 搜索按文件名匹配；文档站的全文检索是另一项功能。
  • 图片、PDF 等二进制文件使用 upload、blob 或 download。
  • blob 或 download 在未指定 --to 且使用 --json 时，会返回 Base64 编码的内容。
  • 访问码来自协作目录，不是管理员密码。请仅把访问码交给有权访问该目录的人或 Agent。
查看某个命令的完整帮助
afile --help
afile workspace --help
afile workspace write --help
